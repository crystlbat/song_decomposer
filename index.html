sync

Your projects live in your own MongoDB, one document per project. Every device reads and writes that one collection. Nothing moves on its own — you send and get work when you want to.

1 Set up the first device

One-time: put the sync endpoint online and paste its address here.

2 Add your phone or tablet

Nothing to type — show a code and point the other device's camera at it.

not linked
  1. Make a free cluster at mongodb.com/atlas → Connect → Drivers → copy the connection string. Under Network Access, allow 0.0.0.0/0 — a function gets a different address on every call, so the key in step 2 is what actually guards this.
  2. Put the code below online with MONGODB_URI set to that connection string and TAPLINE_KEY set to a long random string you invent.
  3. Paste the address it answers on, with ?key=that same key on the end, above — on the laptop and the tablet.

The connection string never leaves your server. This page only ever holds the https address and the key in it.

One file in your Netlify site, at netlify/functions/tapline.js. Nothing to keep alive and free while it sits idle; the first call after a quiet spell takes a second or two to wake.
